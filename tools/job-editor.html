4. How to publish safely
  1. Back up your original source project.
  2. Replace the source project file data/jobs.json with the downloaded JSON.
  3. Run python3 scripts/build_final.py, npm test, npm run validate, and python3 tests/site_audit.py.
  4. Repackage the production files using python3 scripts/package_final.py.
  5. Upload the resulting production ZIP only to Netlify → existing jobpath-india → Deploys.
  6. Confirm real listings and links manually on the public website.

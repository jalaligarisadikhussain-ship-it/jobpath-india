# JobPath India: Professional Four-Position Advertising Layout

## Configured positions
1. Top ad: one existing Cloudflare Adsterra Native Banner, displayed only when an explicit visitor opt-in has been stored.
2. After latest jobs: reserved, disabled pending its own approved code.
3. After official sources: reserved, disabled pending its own approved code.
4. Before footer: reserved, disabled pending its own approved code.

Unused positions are fully hidden. Duplicating the existing native script or container ID would not create independent ad units and could violate network requirements. Real 3–4 monetized ads require site-specific ad-unit tags for each position.

## Consent and content
The large inline allow/decline box no longer displays at the top for first-time visitors. Visitors can access Advertising choices in the footer. When they opt in, the browser reloads once and the configured Adsterra Native Banner can display.

The provider has NOT confirmed dating-category exclusion; we cannot remove just dating or glamour creatives from cross-origin ad scripts with site CSS/JS. Anyone opting in could still see those ads. Obtain written publisher-side category restrictions, or a different provider/unit with appropriate inventory, before describing ads as dating-free.
